Bank Account System (Python OOP)

A simple **Bank Account System** built using **Python Object-Oriented Programming (OOP)** concepts. This project simulates basic banking operations such as depositing money, withdrawing funds, displaying account information, and checking the current account balance.

Features

* Create a bank account with:

* Account Holder
* Account Number
* Initial Balance
* Deposit money
* Withdraw money
* Check current balance
* Display account details
* Prevent invalid deposits
* Prevent withdrawals that exceed the available balance
* Handle invalid withdrawal amounts

Concepts Used

* Classes & Objects
* Constructors (`__init__`)
* Instance Variables
* Instance Methods
* Conditional Statements
* Object State Management
* Basic Input Validation

Technologies
Python 3
